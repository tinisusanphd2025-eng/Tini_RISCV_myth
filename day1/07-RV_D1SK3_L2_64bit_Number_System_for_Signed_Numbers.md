# RV_D1SK3_L2 – 64-bit Number System for Signed Numbers

**Day 1 · Introduction to RISC-V ISA and GNU Compiler Toolchain**  
**Sub-kit D1SK3: Integer Number Representation**

## Overview

Signed representation using two's complement.

## Key Points

- MSB is the sign bit: 0 = positive, 1 = negative.
- Negative value = invert bits + 1 (two's complement).
- Signed range: −2^63 to 2^63 − 1.
