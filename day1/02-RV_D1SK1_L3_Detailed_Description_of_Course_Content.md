# RV_D1SK1_L3 – Detailed Description of Course Content

**Day 1 · Introduction to RISC-V ISA and GNU Compiler Toolchain**  
**Sub-kit D1SK1: Introduction to Basic Keywords**

## Overview

Overview of the RISC-V instruction groups and the 5-day plan.

## Key Points

- Base integer instructions (RV64I): arithmetic, logical, load/store, branch, jump.
- Multiply/divide (M), atomic (A), single/double float (F/D) and compressed (C) extensions.
- ABI: how software uses the 32 registers through standard names (`a0`, `sp`, `ra` …).
- Days 3–5 build a pipelined RV32I CPU in TL-Verilog on Makerchip.
