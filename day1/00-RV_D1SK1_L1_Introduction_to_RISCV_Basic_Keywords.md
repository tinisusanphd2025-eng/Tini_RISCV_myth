# RV_D1SK1_L1 – Introduction to RISC-V Basic Keywords

**Day 1 · Introduction to RISC-V ISA and GNU Compiler Toolchain**  
**Sub-kit D1SK1: Introduction to Basic Keywords**

## Overview

Introduces the vocabulary used throughout the workshop: ISA, instructions, compiler, assembler and the hardware that executes them.

## Key Points

- **ISA (Instruction Set Architecture):** the contract between software and hardware; it defines the instructions a CPU understands.
- **RISC-V:** an open, royalty-free, modular ISA (base sets RV32I/RV64I plus extensions M, A, F, D, C).
- **Pseudo-instructions:** assembler conveniences (e.g. `li`, `mv`) that expand into real instructions.
- **HDL:** the hardware description (Verilog/TL-Verilog) that implements the ISA as a CPU.
- **Board/SoC:** the CPU sits inside a chip with memory, I/O and peripherals.
