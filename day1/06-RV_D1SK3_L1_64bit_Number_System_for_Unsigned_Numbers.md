# RV_D1SK3_L1 – 64-bit Number System for Unsigned Numbers

**Day 1 · Introduction to RISC-V ISA and GNU Compiler Toolchain**  
**Sub-kit D1SK3: Integer Number Representation**

## Overview

How a 64-bit register represents unsigned integers.

## Key Points

- A doubleword = 64 bits = 8 bytes; a word = 32 bits.
- Unsigned range: 0 to 2^64 − 1.
- RV64 registers are 64 bits wide (XLEN = 64).
