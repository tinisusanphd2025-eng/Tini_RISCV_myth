# RV_D1SK1_L2 – From Apps to Hardware

**Day 1 · Introduction to RISC-V ISA and GNU Compiler Toolchain**  
**Sub-kit D1SK1: Introduction to Basic Keywords**

## Overview

Traces how an application written in a high-level language ends up as bits executed by hardware.

## Key Points

- Application → OS → Compiler → Assembler → Binary (machine code) → Hardware.
- The OS handles I/O, memory allocation and low-level system functions.
- The compiler converts C/C++ into ISA-specific assembly; the assembler turns it into binary.
- The CPU, described in an HDL and synthesised into gates, executes that binary.

## Code / Commands

```text
C program  ->  gcc  ->  assembly (.s)  ->  assembler  ->  object/ELF  ->  RISC-V CPU
```
