# RV_D5SK1_L1 – Introduction to Control Flow Hazard and Read-After-Write Hazard

**Day 5 · Complete Pipelined RISC-V CPU Micro-architecture**  
**Sub-kit D5SK1: Pipelining the CPU**

## Overview

Pipelining introduces hazards that must be handled for correct execution.

## Key Points

- **Control-flow hazard:** the next PC is unknown until the branch resolves.
- **Read-after-write (RAW) hazard:** an instruction reads a register before the previous instruction writes it.
- Solutions: stall/invalidate cycles, register bypass, branch redirect.
