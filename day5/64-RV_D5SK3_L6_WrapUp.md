# RV_D5SK3_L6 – Wrap-Up

**Day 5 · Complete Pipelined RISC-V CPU Micro-architecture**  
**Sub-kit D5SK3: Load/Store Instructions and Completing the RISC-V CPU**

## Overview

The finished CPU is a pipelined RV32I core with hazard handling, loads/stores and jumps.

## Key Points

- Pipeline: @0 PC, @1 fetch/decode, @2 RF read + bypass, @3 ALU + RF write + branch, @4–@5 data memory.
- Next steps: add the M extension, caches, or run it on an FPGA.
