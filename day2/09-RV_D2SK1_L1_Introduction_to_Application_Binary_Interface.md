# RV_D2SK1_L1 – Introduction to Application Binary Interface

**Day 2 · Introduction to ABI and Basic Verification Flow**  
**Sub-kit D2SK1: Application Binary Interface (ABI)**

## Overview

The ABI is the interface through which an application accesses hardware registers via system calls and calling conventions.

## Key Points

- ISA is visible to the programmer at the user/system level; the ABI defines how programs use it.
- RISC-V has 32 integer registers `x0`–`x31`, each XLEN bits wide.
- Function arguments pass in `a0`–`a7`; return value comes back in `a0`.
