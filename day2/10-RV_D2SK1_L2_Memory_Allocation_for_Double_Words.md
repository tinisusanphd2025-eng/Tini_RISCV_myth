# RV_D2SK1_L2 – Memory Allocation for Double Words

**Day 2 · Introduction to ABI and Basic Verification Flow**  
**Sub-kit D2SK1: Application Binary Interface (ABI)**

## Overview

How 64-bit data is laid out in byte-addressed memory.

## Key Points

- Memory is byte-addressable; a doubleword occupies 8 consecutive addresses.
- RISC-V is **little-endian**: the least significant byte is at the lowest address.
- Doubleword addresses step by 8 (0, 8, 16 …).
