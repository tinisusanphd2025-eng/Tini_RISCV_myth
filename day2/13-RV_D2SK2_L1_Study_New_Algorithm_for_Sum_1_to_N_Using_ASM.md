# RV_D2SK2_L1 – Study New Algorithm for Sum 1 to N Using ASM

**Day 2 · Introduction to ABI and Basic Verification Flow**  
**Sub-kit D2SK2: Labwork Using ABI Function Calls**

## Overview

Splits the program: `main` in C, the summing loop in an assembly function.

## Key Points

- C passes `count` (a0) and initial value (a1) to `load`.
- The ASM loop increments and accumulates, returning the result in a0.
- Shows how the ABI lets C and assembly cooperate.
