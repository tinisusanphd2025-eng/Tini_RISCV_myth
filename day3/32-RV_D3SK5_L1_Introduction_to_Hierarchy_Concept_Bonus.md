# RV_D3SK5_L1 – Introduction to Hierarchy Concept (Bonus)

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK5: Hierarchy (Bonus)**

## Overview

TL-Verilog hierarchy (`/scope[N:0]`) replicates logic, e.g. a register file or multiple cores.

## Key Points

- `/xreg[31:0]` builds 32 register instances with one description.
- Signals in other scopes are referenced as `/top|pipe>>1$sig`.
