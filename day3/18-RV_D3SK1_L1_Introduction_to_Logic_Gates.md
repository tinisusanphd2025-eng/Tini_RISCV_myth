# RV_D3SK1_L1 – Introduction to Logic Gates

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK1: Combinational Logic in TL-Verilog Using Makerchip**

## Overview

Refresher on basic gates and Boolean operators.

## Key Points

- Gates: AND, OR, NOT, NAND, NOR, XOR, XNOR.
- Verilog operators: `&&`, `||`, `!`, `^`, `~`.
- A full adder is built from XOR (sum) and AND/OR (carry).
