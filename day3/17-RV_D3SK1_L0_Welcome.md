# RV_D3SK1_L0 – Welcome

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK1: Combinational Logic in TL-Verilog Using Makerchip**

## Overview

Introduces TL-Verilog (Transaction-Level Verilog) and Makerchip, the browser IDE used for all remaining labs.

## Key Points

- TL-Verilog separates *what* the logic does from *when* (timing) it happens.
- Makerchip compiles TL-Verilog → SystemVerilog and shows waveforms, diagram and visualisation.
