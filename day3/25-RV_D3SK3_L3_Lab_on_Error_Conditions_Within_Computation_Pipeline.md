# RV_D3SK3_L3 – Lab on Error Conditions Within Computation Pipeline

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK3: Pipelined Logic**

## Overview

Propagates error flags down a pipeline (bad input, overflow, illegal op) so the final stage reports any error.

## Key Points

- Errors at each stage OR'ed with the previous stage's error.
- Demonstrates `|pipe` scope and `@n` stages.
