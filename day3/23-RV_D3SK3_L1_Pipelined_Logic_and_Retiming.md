# RV_D3SK3_L1 – Pipelined Logic and Retiming

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK3: Pipelined Logic**

## Overview

Pipelines split logic into stages so each stage fits a clock cycle, raising frequency.

## Key Points

- Example: Pythagoras' theorem split into stages @1, @2, @3.
- TL-Verilog: move logic between stages without rewriting it (easy retiming).
- Pipeline flops are implied by stage numbers – far less code than SystemVerilog.
