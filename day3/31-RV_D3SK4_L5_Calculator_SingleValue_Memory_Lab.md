# RV_D3SK4_L5 – Calculator Single-Value Memory Lab

**Day 3 · Digital Logic with TL-Verilog and Makerchip**  
**Sub-kit D3SK4: Validity**

## Overview

Adds memory recall (`op = 101`) and memory store (`op = 100`) to the calculator.

## Key Points

- `$mem` stores `$val1` on op 100 and is held otherwise.
- Output mux returns `>>2$mem` on recall.
