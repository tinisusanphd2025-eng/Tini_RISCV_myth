# RV_D4SK3_L5 – Concept of Array and Register File Details

**Day 4 · Basic RISC-V CPU Micro-architecture**  
**Sub-kit D4SK3: RISC-V Control Logic**

## Overview

How the register file is modelled as an array with two read ports and one write port.

## Key Points

- Write happens at the end of the cycle; reads are combinational.
- In TL-Verilog it is a `/xreg[31:0]` hierarchy.
