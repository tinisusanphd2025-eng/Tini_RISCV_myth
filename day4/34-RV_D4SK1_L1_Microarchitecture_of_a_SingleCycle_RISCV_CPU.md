# RV_D4SK1_L1 – Microarchitecture of a Single-Cycle RISC-V CPU

**Day 4 · Basic RISC-V CPU Micro-architecture**  
**Sub-kit D4SK1: Microarchitecture and Testbench for a Simple RISC-V CPU**

## Overview

Block diagram of the CPU to be built: PC → IMem → Decode → RF read → ALU → RF write, plus branch logic.

## Key Points

- Implements a subset of RV32I first, then the full base set.
- Makerchip shell provides instruction memory, register file and data memory macros.
